# Intro to Git — Reading Questions

## What Git Is

1. Why is one project folder with a Git history more useful than a folder of copies like `report-final-v2-REAL.docx`?

2. Besides a snapshot of the files, every commit stores a message, an author, and a date. Why does a history need that information, and not just the snapshots?

3. Why does Git put a staging area between the working directory and the repository, instead of committing every change we've made?

4. Git is distributed. What can we do with no network connection at all, and why is that possible?

## GitHub

1. Git works fully without GitHub, but GitHub doesn't work without Git. Why?

2. A remote is just another full copy of the repository. What makes the copy on GitHub the "official" one?

3. Why does a team share work through one remote instead of sending commits directly between each other's machines?
